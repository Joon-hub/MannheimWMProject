# MannheimWMProject

## Overview

**MannheimWMProject** is a data mining and web mining project developed for the IE500 course at the University of Mannheim. The project demonstrates practical applications of modern Natural Language Processing (NLP) and data mining techniques, utilizing Python and Jupyter notebooks. Key components include data collection, preprocessing, and advanced text analysis with models such as BERT.

---

## Features

- **Web Mining:** Automated data collection from web sources.
- **Data Preprocessing:** Cleaning and preparation of raw text data for analysis.
- **Text Analysis:** Implementation of NLP techniques, including BERT-based text embeddings and classification.
- **Jupyter Notebooks:** All steps are documented and reproducible in interactive notebooks.
- **Modular Codebase:** Well-organized Python scripts for easy extension and reuse.

## Getting Started

### Prerequisites

- Python 3.8+
- pip


### Installation

1. **Clone the repository:**

```bash
git clone https://github.com/Joon-hub/MannheimWMProject.git
cd MannheimWMProject
```

2. **Install dependencies:**

```bash
pip install -r requirements.txt
```

3. **Open Jupyter Notebooks:**

```bash
jupyter notebook
```

Navigate to the `notebooks/` directory to explore the analysis.

---

## Usage

- Run the notebooks in sequence to reproduce the data mining workflow.
- Modify the scripts in the `scripts/` folder to adapt to new datasets or analysis tasks.
